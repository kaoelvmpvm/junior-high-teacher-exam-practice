# 國中教甄｜知識刷題室

一套可直接部署在 **GitHub Pages** 的「國中教師甄試教育專業科」刷題網站。採純前端 HTML、CSS、JavaScript，不需要伺服器、帳號或 API 金鑰。

> **重要提醒：** 目前隨附 **18 題原創示範題**，用來驗證功能與解析格式；它們 **不是** 歷屆教甄原題。先前整理的 1,100 餘題尚未匯入本 Repository，不應將示範題數視為完整題庫。

## 已有功能

- **自主組卷：** 依練習模式、知識領域、題庫來源、題數、隨機或依題號排序選題。
- **即時判題：** 單選題作答後顯示正確答案與逐項選項解析。
- **知識型詳解：** 支援核心概念、破題關鍵、易錯觀念、考場記憶提示。
- **錯題本：** 答錯自動收錄；重新答對自動移出，也可以手動移除。
- **收藏題：** 可在作答時加入收藏，供集中複習。
- **個人學習概況：** 題數、歷次作答次數、正確率、待複習錯題及主題分布。
- **本機題庫匯入：** 透過 JSON 上傳自訂題目；略過重複 ID 與格式不符題目。
- **資料備份：** 題庫與學習紀錄可分別匯出；學習紀錄可再匯入還原。
- **響應式網頁：** 桌機與手機皆可使用，支援鍵盤 1–6 選答案。

## 網站發布（GitHub Pages）

1. 開啟本 Repository 的 **Settings → Pages**。
2. 在 **Build and deployment** 區塊，將 **Source** 設為 **Deploy from a branch**。
3. 選擇 main 分支及 /(root) 目錄，點選 **Save**。
4. GitHub Pages 完成部署後，網站網址通常是：
   https://kaoelvmpvm.github.io/junior-high-teacher-exam-practice/

若已事先設定 Pages，更新 main 分支後通常會自動重新發布。可在 **Actions** 或 **Settings → Pages** 確認部署狀態。

直接雙擊本機 index.html 可能因瀏覽器的 file:// 安全限制而無法載入 data/questions.json。本機測試請在專案目錄執行 python -m http.server 8000，再開啟 http://localhost:8000/。

## 題庫 JSON 格式

檔案可為題目陣列，或採下列包含 questions 的格式：

~~~json
{
  "version": 1,
  "questions": [
    {
      "id": "MY-001",
      "category": "教育心理學",
      "topic": "學習理論",
      "year": "115",
      "exam": "自建練習題",
      "stem": "這裡填入題目敘述，下列何者正確？",
      "options": ["選項 A", "選項 B", "選項 C", "選項 D"],
      "answer": 1,
      "explanation": "整體概念詳解。",
      "optionExplanations": ["A 的解析", "B 的解析", "C 的解析", "D 的解析"],
      "keyPoint": "破題關鍵。",
      "trap": "易錯觀念。",
      "mnemonic": "考場記憶提示。"
    }
  ]
}
~~~

### 欄位說明

| 欄位 | 必填 | 說明 |
| --- | --- | --- |
| id | 建議 | 唯一題號；未提供時由題幹與選項內容產生穩定 ID。重複 ID 會略過。 |
| stem | 是 | 題目敘述。亦接受 question。 |
| options | 是 | 2–6 個非空選項。亦接受 choices。 |
| answer | 是 | 正確選項的 **0 起算索引**：0=A、1=B、2=C；亦接受字母 A、B 等。 |
| category | 否 | 知識領域，用於篩選。 |
| topic | 否 | 子主題。 |
| year | 否 | 年度，可為民國年字串。 |
| exam | 否 | 題庫出處描述。 |
| explanation | 否 | 核心概念詳解。 |
| optionExplanations | 否 | 按 A–F 順序填入選項解析的陣列。 |
| keyPoint | 否 | 破題關鍵。 |
| trap | 否 | 易錯觀念。 |
| mnemonic | 否 | 記憶口訣或提示。 |

**匯入限制：** 一次最多 3,000 題、JSON 檔案上限 4MB。資料超過瀏覽器儲存額度時，請改用分批上傳或將正式題庫整理進 data/questions.json。完整題庫最適合以 Repository 內的 JSON 檔案管理，而非長期全部依賴 localStorage。

**題目校對：** 歷屆題庫如有缺圖、刪題、複選題、爭議答案或法規更新，應於轉檔前人工檢核。現有系統支援單一正確答案；含圖片與複選題需另行擴充，不應強行轉換為單選題。

## 資料與隱私

- 學習紀錄、錯題、收藏、從網頁匯入的題目使用本機 localStorage。
- 系統不會將個人作答紀錄傳到遠端；重新整理網頁後仍會保留同一瀏覽器的紀錄。
- **不同裝置／不同瀏覽器不會自動同步。** 若要搬移進度，請同時匯出「個人題庫」與「學習紀錄」，在新瀏覽器先匯入題庫、再還原紀錄。
- 若清除網站資料、改用無痕視窗或遇到儲存額度限制，可能遺失本機資料。
